ПРОСМОТР ПАПКИ — версия 1.3

Открываешь одну картинку через «Просмотр папки» — изображения из той же
папки передаются стандартному приложению Apple «Просмотр» одним набором.

СОРТИРОВКА ИЗ FINDER

1. Открой нужную папку в Finder и включи «Список» сочетанием ⌘2.
2. Выбери столбец: Имя, Дата изменения, Дата создания или Размер.
   Повторное нажатие заголовка меняет направление сортировки.
3. Открой одну картинку через «Просмотр папки».
4. Разреши приложению доступ к Finder, если macOS его запрашивает.

Запускатель читает столбец и направление из первого подходящего окна
Finder. Чужое окно с другой папкой не влияет на выбор. Если одна папка
открыта в двух окнах, берутся параметры ближайшего к переднему плану окна.
Порядок считывается заново при каждом запуске; уже открытая подборка сама
не перестраивается. После изменения сортировки закрой окно этой подборки
в «Просмотре» с обычной проверкой несохранённых правок и открой картинку снова.

Дата — свойство файла, выбранное в Finder, а не дата съёмки из EXIF.
Размер — размер файла в байтах, а не ширина или высота картинки.
При одинаковом размере или дате используется естественный порядок имён:
например, 2 перед 10.

Автоматическое считывание в 1.3 предназначено для режима «Список» и четырёх
перечисленных столбцов. Значки, колонки, галерея, ручная раскладка, результаты
поиска, группировка и сортировка по дате добавления пока не воспроизводятся.
Если подходящего окна нет, критерий не поддерживается или доступ к Finder
запрещён, используется имя по возрастанию. Причина видна в журнале проверки.

Запускатель передаёт отсортированный список самому «Просмотру». В некоторых
версиях «Просмотра» собственная сортировка миниатюр или уже открытые документы
могут влиять на отображаемую последовательность. Копирование порядка внутри
окон macOS 26 нужно проверить на самом Mac. Диагностика пишет найденные
столбец, направление и применённый критерий в журнал.

УСТАНОВКА И ОБНОВЛЕНИЕ

1. Распакуй весь ZIP. Оставь папку source рядом с установщиком.
2. Запусти Install_PreviewFolder.command. Откроется Терминал.
   Пароль администратора, Python, Homebrew и Xcode не требуются.
3. После завершения Finder покажет приложение «Просмотр папки».
   Оно находится в ~/Applications/Просмотр папки.app.

Установщик сначала проверяет встроенные компоненты macOS. Старое приложение
заменяется после успешной сборки, его резервная копия сохраняется рядом.
Закрывается только предыдущий экземпляр запускателя; стандартный «Просмотр»
и его документы не закрываются. Идентификатор приложения сохраняется, поэтому
после обновления назначение по умолчанию обычно не требуется повторять.
Запрос разрешения на чтение Finder может появиться заново после обновления.

Если .command не запускается двойным щелчком: открой Терминал, набери bash
и пробел, перетащи нужный .command в окно и нажми Enter.

НАСТРОЙКА СТАНДАРТНОГО «ПРОСМОТРА»

«Просмотр» → Настройки (⌘,) → Изображения → «Открывать группы файлов в том
же окне». Без этого параметра файлы могут открыться в отдельных окнах.
В «Просмотре» включи Вид → Миниатюры (⌥⌘2), нажми миниатюру и листай ↑ ↓.

ДВОЙНОЙ ЩЕЛЧОК ПО КАРТИНКЕ

В Finder выдели JPG → ⌘I → «Открывать в приложении» → «Просмотр папки» →
примени ко всем файлам этого типа («Изменить всё…» / «Настроить»).
Повтори отдельно для PNG, JPEG, TIF/TIFF и других нужных расширений.
Для однократного открытия: правая кнопка → Открыть в приложении → Другое… →
~/Applications/Просмотр папки.app.

ДИАГНОСТИКА

Открой папку с несколькими JPG/PNG в Finder списком и выбери сортировку.
Запусти Test_PreviewFolder.command из нового архива. Когда появится выбор
картинки, выбери файл из этой же папки и разреши доступ к Finder.
В журнале появятся строки «Finder column=...» и «Sorting: ...».
Для проверки через Терминал macOS может отдельно запросить доступ Терминалу
к Finder; у установленного приложения свой запрос.

Если картинки не открылись или порядок не совпал, сохрани текст окна
Терминала. Он также записывается в
~/Library/Logs/PreviewFolder/Terminal-check-<дата>.log.
Журнал последнего обычного запуска: ~/Library/Logs/PreviewFolder/last-run.log.
Для проверки установленного приложения после успешной установки открой файл
обычным двойным щелчком, поскольку источник в архиве проверяет другой процесс.

ОСТАЛЬНОЕ ПОВЕДЕНИЕ

• Берёт файлы только из текущей папки; вложенные папки не сканирует.
• Не изменяет сортировку, окна, выделение или файлы Finder.
• Пропускает скрытые соседние файлы, каталоги и символические ссылки.
• Не включает PDF, AI, EPS, PS и SVG в набор растровых картинок.
• Базовые форматы: JPG, PNG, TIFF, GIF, BMP, JPEG 2000 и некоторые другие.
  Дополнительные расширения определяются возможностями macOS.
• Если изображений больше 120 или их суммарный размер от 512 МБ, предлагает
  открыть всю папку или только выбранную картинку.
• Если чтение папки запрещено, объясняет проблему и пробует открыть выбранный
  файл. Разрешения проверяются в «Конфиденциальность и безопасность».

Сам запускатель не изменяет и не копирует картинки. Изменения, которые ты
сама внесёшь инструментами «Просмотра», сохраняются обычным способом.
Облачные оригиналы могут загружаться средствами macOS при открытии.

ОТКАТ

В свойствах JPG/PNG/TIFF снова выбери стандартный «Просмотр» и примени
ко всем файлам этого типа. Затем удали ~/Applications/Просмотр папки.app
через Finder. Журналы в ~/Library/Logs/PreviewFolder и резервные приложения
при желании можно удалить отдельно.

ПРОВЕРКИ И СОВМЕСТИМОСТЬ

Приложение собирается на самом Mac встроенной командой osacompile.
В пакете указана минимальная версия macOS 10.13. Фактическая совместимость
старых версий требует проверки. На Mac с Apple Silicon и Intel используется
системный интерпретатор; внешние пакеты не требуются.

Проверены синтаксис, отбор изображений, сортировка по четырём критериям,
обратный порядок, одинаковые и отсутствующие значения, выбор подходящего окна
Finder, повторное чтение его состояния и отказы доступа. Сохраняется проверка
передачи нативных параметров, воспроизводящая исправленный сбой NSNull из 1.1.
Тесты моделируют macOS и Finder; сама среда подготовки работает на Linux.
Работу разрешений, текущих свойств Finder и порядок миниатюр нужно проверить
на настоящем Mac. Исходный код открыт в папке source.
