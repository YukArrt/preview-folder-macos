# Просмотр папки / PreviewFolder

Многие владельцы Макбуков согласятся, что программе просмотра изображений для MacOS не хватает маленького удобства: открыв одну картинку нельзя просто листать дальше и увидеть все изображения в текущей папке - нужно либо выделять группу файлов, либо менять вид папки на "Галерею", что, лично мне, неудобно.
PreviewFolder — небольшой "запускатель". Он собирает изображения из текущей папки и сам передаёт их приложению Apple «Просмотр». Заранее выделять все файлы не требуется.

Откройте одну картинку и листайте остальные изображения из той же папки в стандартном приложении macOS «Просмотр».

Текущая версия: **1.3**.

## Возможности

- Открытие изображений из одной папки по двойному щелчку на одном файле.
- Листание через панель миниатюр стандартного «Просмотра» клавишами **↑ / ↓**.
- Работа без Python, Homebrew и Xcode: приложение собирается встроенными средствами macOS.
- Проверка размера подборки перед открытием большого числа тяжёлых файлов.
- Отдельный сценарий диагностики с журналом работы.
- Экспериментальное чтение сортировки Finder: имя, дата изменения, дата создания и размер в режиме «Список».

## Установка

1. На странице проекта нажмите **Code → Download ZIP** и распакуйте архив целиком.
2. Откройте **Терминал**.
3. Напечатайте `bash`, затем пробел, перетащите файл `Install_PreviewFolder.command` из распакованной папки в окно Терминала и нажмите **Enter**.
4. Дождитесь завершения установки. Приложение появится по адресу `~/Applications/Просмотр папки.app`.

Папка `source` должна оставаться рядом с установщиком. Пароль администратора не требуется.

После успешной установки распакованную папку можно перенести или удалить: установленное приложение работает самостоятельно.

## Настройка «Просмотра»

В стандартном приложении Apple «Просмотр» откройте **Настройки → Изображения** и выберите **«Открывать группы файлов в том же окне»**.

Для первой проверки:

1. В Finder нажмите правой кнопкой на JPG или PNG.
2. Выберите **Открыть в приложении → Другое…** и укажите `~/Applications/Просмотр папки.app`.
3. Разрешите доступ к папке, если macOS его запрашивает.
4. В «Просмотре» включите **Вид → Миниатюры**, нажмите миниатюру слева и листайте **↑ / ↓**.

## Открытие по умолчанию

1. Выделите один JPG в Finder и нажмите **⌘I**.
2. В разделе **«Открывать в приложении»** выберите **«Просмотр папки»**.
3. Примените изменение ко всем файлам этого типа кнопкой **«Изменить всё…»** / **«Настроить»**.
4. Повторите для PNG, JPEG, TIF/TIFF и других нужных расширений.

После этого двойной щелчок на картинке будет запускать PreviewFolder.

## Сортировка Finder в версии 1.3

1. Откройте нужную папку в Finder в режиме **«Список» — ⌘2**.
2. Выберите столбец **Имя**, **Дата изменения**, **Дата создания** или **Размер**.
3. Откройте картинку через PreviewFolder и разрешите приложению доступ к Finder.

Запускатель читает выбранный столбец и направление сортировки из подходящего окна Finder. Если открыт другой каталог, его параметры не используются. Если подходящего окна нет или доступ запрещён, применяется сортировка по имени.

Порядок считывается при открытии. После смены сортировки закройте окно этой подборки в «Просмотре», учитывая несохранённые изменения, и откройте картинку снова.

**Статус функции:** чтение сортировки Finder и сохранение порядка внутри «Просмотра» требуют дополнительной проверки на реальных Mac. Сам «Просмотр» может применять собственную сортировку миниатюр. Режимы значков, колонок и галереи, группировка и дата добавления в этой версии не воспроизводятся.

## Диагностика

Запустите `Test_PreviewFolder.command` через Терминал тем же способом: `bash`, пробел, перетаскивание файла и **Enter**.

Для проверки сортировки предварительно откройте нужную папку в Finder списком. В диалоге выберите изображение из этой папки. В выводе будут строки `Finder column=...` и `Sorting: ...`.

Журналы сохраняются в `~/Library/Logs/PreviewFolder/`.

Если открываете issue с ошибкой, укажите:

- версию macOS;
- процессор: Apple Silicon или Intel;
- версию PreviewFolder;
- шаги, после которых появилась ошибка;
- соответствующий фрагмент диагностического вывода.

Перед публикацией журнала просмотрите его: сообщения об ошибках могут содержать пути и имена файлов.

## Совместимость и ограничения

Основная функция открытия папки была подтверждена на **macOS 26.5.1, Apple Silicon (arm64)**. В пакете заявлена минимальная версия macOS 10.13; совместимость со старыми системами и Intel требует отдельной проверки.

- Поддержка форматов зависит от macOS и приложения «Просмотр».
- Вложенные папки не сканируются.
- Если изображений больше 120 или суммарный размер файлов составляет от 512 МБ, появляется выбор: открыть всю папку или только выбранное изображение.
- Сам запускатель не изменяет и не копирует изображения. Правки, внесённые пользователем в «Просмотре», сохраняются его обычными средствами.

## Удаление

В свойствах нужных типов изображений снова назначьте стандартный «Просмотр» приложением по умолчанию. Затем удалите `~/Applications/Просмотр папки.app` через Finder.

Журналы и резервные копии прежних версий можно удалить отдельно.
